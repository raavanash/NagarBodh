## 3. Presenter Click Sequence (No Menu Searching)

2. `Why Recommendation & Brief` (Opens Explainable Dossier)
3. `Generate Decision Brief` (Synthesizes 8-section executive brief)
4. `Prioritize in Pipeline` (Moves project to Capital Pipeline)
5. `Approve Intervention` (Authorizes intervention record)
6. `Measure Impact` (Inspects modeled before/after deltas)
7. `Reset Demo` (Returns cleanly to 08:00 AM baseline)

## 4. Failure Recovery Matrix

| Scenario | Immediate Presenter Action | System Behaviour |
| :--- | :--- | :--- |
| **Gemini API Timeout / Offline** | Click `Generate Decision Brief` normally | Automatically triggers `DETERMINISTIC FALLBACK` in <5ms. Displays identical 8-section brief with exact same numbers and amber status tag. |
| **Internet Drop** | Continue demo locally on `http://localhost:5173` | All domain calculation engines, deterministic dossiers, and local state machines run 100% in-browser offline. |
| **Live Provider Drop** | Leave ingestion on default mode | System automatically defaults to deterministic scenario simulation without crashing. |
| **Presenter Gets Disoriented** | Click floating `JUDGE MODE` pill | Select the next numbered step (`1` through `6`) from the Stepper modal. |
| **Unexpected State / Dirty Data** | Click `Reset Demo` in Demo Command Center | Instantly resets all state, timeline, interventions, and displays toast *"Demo reset — canonical baseline restored"*. |
